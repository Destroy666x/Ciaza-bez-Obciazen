# Ciaza-bez-Obciazen
Project for ImpactHER HackYeah 2026 task.

My idea is to create a free, open source "guide" application to support mothers through their pregnancy journey step by step. There are some of them that already do that, but they are generic for women globally, I aim to solve the problem of lack of knowledge/support in Poland specifically, in as detailed way as possible. Apart from doing what they are - providing e.g. week by week health information, I want to uniquely add features that localize it for Poland. For example:
- concise, user-friendly knowledge documents for: laws, official procedures, how to apply for and receive financial aid like 800+, benefits for disabled children or unemployment benefits, etc.
- a map of services helpful for pregnant women, e.g.: hospitals/clinics, gynecologists, birthing/parenting classes, dieticians, psychology/psychiatry specialists, physiotherapists, MOPS, pregnancy/baby stores, etc. - with user ratings
- timeline with suggestions on what to do at each pregnancy stage - linking to proper documents
- quick contact for urgent human support - phones, mails, etc.
On all the information within the app I also plan to train an AI model (based on just accurate info from the app itself) that will be usable inside a chat so that information can be found quickly by the users.
